# 实验性功能

实验选项位于设置页的「实验性功能」，修改后需要点击「保存偏好」。当前版本共提供两个实验性功能：

| 功能               | 默认状态 | 作用                                                   |
| ------------------ | -------- | ------------------------------------------------------ |
| GIF 本地转码       | 开启     | 将单项 GIF 媒体从 X 提供的 MP4 转为 `.gif`             |
| 动态拼图与视频画框 | 关闭     | 将含动态媒体的拼图输出为 MP4，或给普通视频添加来源画框 |

处理使用本机 CPU。引擎随扩展打包，在执行相关任务时加载；处理能力受素材、浏览器内存及设备性能影响，Android 表现**通常欠佳**。

## GIF 本地转码

### 输出规则

GIF 输出保持完整时长并无限循环，不包含音轨；默认最长边为 960 px，保持宽高比且不放大，最高 20 fps，不升采样低帧率。使用自适应调色板，最多 256 色。

GIF 可以独立选择写入来源。转码开启时，先生成 `.gif`，再写入来源；关闭时保存原始 MP4，并按所选方式决定是否写入来源。GIF 不提供上方或下方画框。

### 输入限制

| 限制         | 默认值    |
| ------------ | --------- |
| 输入文件大小 | 64 MiB    |
| 源时长       | 60 秒     |
| 源单帧像素数 | 8,294,400 |

各项设为 `0` 表示不限。

超出任一限制时，将使用已经下载的原始 MP4 保存，并在任务中说明原因。下载、探测或转码失败会报错；取消任务不会触发保存。转码不设自动超时，必要时从任务页取消。

## 动态拼图与视频画框

### 开启后怎样使用

开启并保存后，重新打开导出面板：

- 推文中有 GIF 或视频时，「拼接全部媒体」可生成 MP4；只有照片时仍生成图片。
- 普通视频可选择上方画框或下方画框，再保存媒体。
- 拼图沿用「照片 / 拼图」中选择的画框位置，以及设置页的无缝／画廊样式。

关闭后，面板隐藏动态处理选项，后台也会拒绝新的动态任务。已开始的任务可继续执行或手动取消。原文件、写入来源、纯照片拼接和静态卡片仍可使用。

### 拼接与输出规则

各项按原顺序横排，统一到最矮素材的高度、保持宽高比，并取偶数像素尺寸。静态图片全程保持不动，所有动态素材同时开始，以最长一项的时长结束；较短项停在末帧。

声音只取第一条实际有音轨的普通视频，音轨不足的部分补静音。GIF 不提供声音。

输出为 H.264／yuv420p MP4，有音轨时使用 AAC。帧率采用动态素材中的最高帧率，无法探测时使用 24 fps。每次最多处理四项素材，只执行一个 FFmpeg 任务；旋转元数据与非方形像素素材暂不支持。

卡片始终是静态图片，开启此功能也不会把卡片变成视频。

### 处理限制

设置提供四组快捷配置，也可以单独填写各项上限：

| 配置         | 输入总大小 | 最长动态项时长 | 单项源图像／最终输出像素数 | 输出帧率 |
| ------------ | ---------- | -------------- | -------------------------- | -------- |
| 保守         | 64 MiB     | 30 秒          | 2,073,600                  | 30 fps   |
| 标准（默认） | 256 MiB    | 180 秒         | 4,147,200                  | 30 fps   |
| 高清         | 512 MiB    | 600 秒         | 8,294,400                  | 60 fps   |
| 不限         | 不限       | 不限           | 不限                       | 不限     |

单项填 `0` 可关闭该项限制。最终输出的像素数包含画框；这些值用于限制处理负担，不是 X 的账号上传配额，也不保证上限内的素材都能成功处理。

### 超限与失败

| 情况                 | 结果                                           |
| -------------------- | ---------------------------------------------- |
| 视频画框超出处理限制 | 使用已下载内容保存原媒体，并说明原因           |
| 动态拼图超出处理限制 | 改为静态拼图，动态项使用已有预览图，并说明原因 |
| 静态拼图缺少必要预览 | 报错，不省略素材                               |
| 下载、解码或编码错误 | 报错，不按超限方式回退                         |
| 手动取消             | 终止处理并释放资源                             |

大小限制约束转码输入，画框超限后保存原媒体仍需完成原文件下载。不限配置也受浏览器、Canvas、WASM 内存和编码器能力约束。

## 进度、取消与诊断

确认入队后，可以关闭原推文，从任务页查看下载、引擎加载、探测和编码进度。视频处理没有自动超时；长时间无进展或设备负担过大时，可手动取消，取消会终止处理 Worker 并释放资源。

每个动态任务可下载诊断 JSON；一个任务包含多次动态编码时，保留最后一次处理的报告，取消或失败时也可下载已收到的诊断。诊断随任务缓存管理，保留期限见[使用](usage.md#缓存期限与清理)。

报告包含浏览器及引擎版本、素材尺寸／时长／帧率／音轨、编码参数、各阶段耗时、进度和内存容量等数值，不保存媒体帧、推文正文或媒体下载地址。报告中的 WASM 容量不等于实际已用内存，也不代表 Firefox 进程总内存。
