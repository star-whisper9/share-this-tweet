# 快速开始

## 安装

用桌面 Firefox 或 Firefox Android 打开[分享有据的附加组件商店页面](https://addons.mozilla.org/zh-CN/firefox/addon/share-this-tweet/)，点击「添加到 Firefox」并确认安装。需要桌面 Firefox 140 或 Android Firefox 142 及以上版本。

## 第一次导出

1. 在 Firefox 中打开 X，进入一条推文的**详情页**。安装前已打开的页面请先刷新。
2. 点击「分享有据」的导出入口，打开面板。
3. 选择要保存的媒体，再点击「保存 N 项媒体」；想保存正文与配图，选择保存推文卡片；只需文字和链接，选择复制推文文字。
4. 保存操作显示「已加入队列」后，可以离开原推文。通过扩展弹窗或面板中的「查看导出任务」查看进度。

桌面 Firefox 会自动保存处理完成的文件。Android 需要保留任务页，完成后手动保存，并在下载目录中确认收到了文件。

接下来可以查看[功能介绍](features.md)，或进入[设置](settings.md)调整画框、文件名和复制格式。其他安装方式见[安装](installation.md)，详细操作见[使用](usage.md)。
