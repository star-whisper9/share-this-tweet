# 动态拼图与画框（实验）

此功能已接入开发版，尚未发布到 AMO 或 GitHub Release。

## 操作

- 推文有 GIF／视频时，“拼接全部媒体”输出 MP4；只有照片时，继续使用原来的图片拼接。
- 拼图的来源条跟随“照片 / 拼图”行里的原图、上框或下框；间隔仍使用设置页的无缝／画廊选项。
- 单项视频和 GIF 在动态媒体行选择上框或下框，再保存媒体。原文件、写入来源仍保留，不经过转码。
- 图片／网格卡片／单行卡片仍为静态输出。
- 处理过程中显示下载、加载、探测和编码进度，可取消。切换推文或断开面板所属页面会取消其动态任务；仅关闭面板不会取消，可重新打开查看。

## 首版规则

静态图全程不动，所有动态项同时开始，以最长动态项的时长结束，较短项停在末帧。只保留第一条实际带音轨的普通视频的声音，音轨不足的部分补静音；GIF 不提供声音。输出 H.264 / yuv420p MP4，音轨为 AAC。

最多 4 项素材、合计 64 MiB、最长 30 秒；媒体画面不超过 1280 × 720、24 fps，来源条另加在上下方。图片等高排列，宽高比在偶数像素取整范围内保留。源媒体单边不能超过 8192px、总像素不能超过 3200 万；旋转元数据和非方形像素素材暂不支持。超限或不支持会明确报错，不裁短、不省略素材、不退回静态输出。

浏览器同时处理一个 FFmpeg 任务。编码内部限制 2 分钟，包含下载、加载、画框生成的整个任务限制 5 分钟。取消／超时／页面断开都会终止 Worker 并释放资源。

## 实现

内容脚本通过专用 runtime Port 请求扩展后台处理。后台限制媒体域名、逐块检查下载大小，再把 Blob 交给单线程 Worker。Worker 用真实 ffprobe 读取尺寸、时长和音轨，返回画框所需宽度；后台复用 Canvas 来源条渲染后，将 PNG 回传给 Worker 一并编码。

`@ffmpeg/core` 固定为 0.12.10，其 JavaScript/WASM 在构建时复制到扩展自身目录，不从 CDN 加载。CSP 仅增加 `wasm-unsafe-eval`。核心 WASM 未压缩约 31 MiB，因此安装包会明显变大；首次动态操作才加载引擎，结束后释放 Worker。

- `src/core/video-plan.ts`：尺寸、时长、音轨选择和 FFmpeg 参数。
- `src/core/video-engine.ts`：探测、布局、帧条握手和编码。
- `src/workers/video-render.worker.ts`：加载本地核心、完整 ffprobe JSON、错误日志与进度。
- `src/background/video-render.ts`：下载边界、排他处理、Canvas 画框和取消。
- `src/core/video-client.ts`：面板与后台连接、进度、心跳和取消。

第三方来源和许可证见 `src/vendor/ffmpeg/NOTICE.txt`，构建会随核心打包。

## 验证

`npm run check` 验证类型、单元测试与构建；`npm run lint:extension` 检查扩展清单。

本机安装 `ffprobe` 后，可运行 `npm run verify:video`。它在 Node Worker 中执行打包后的真实 ffmpeg.wasm Worker，模拟浏览器的本地资源加载，验证混合拼接、GIF 画廊加下框、单视频上框／下框的 MP4 尺寸、时长、帧率和音轨。此检查不等于 Firefox 扩展实机或手机性能测试。

人工回归：在桌面及 Android Firefox 分别测试短 GIF + 照片、带声音视频上下画框、取消后再导出、超过 30 秒的拒绝路径，以及原文件／写入来源没有被改为转码。
