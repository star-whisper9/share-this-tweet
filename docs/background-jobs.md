# 后台导出任务（开发版）

保存媒体（原文件、写入来源、画框）、拼接全部媒体、网格卡片和单行卡片均提交为后台任务。复制文字仍在原页面即时执行，以保留剪贴板操作的用户手势。

## 使用

- 等面板显示“已加入队列”后，即可关闭面板、返回推文列表或关闭原推文标签页。提交尚未确认时，请先等待。
- 桌面 Firefox 自动保存，只有浏览器报告下载完成后才标记文件已保存。
- Android 自动打开任务页。请保持任务页打开，处理完成后点击文件保存；“已开始保存”只表示已发起保存，扩展无法确认系统最终落盘结果。
- 从扩展弹窗或导出面板的“查看导出任务”进入任务页，可取消、重试、保存输出或下载诊断。
- 同一时间处理一个任务。多项媒体中一项失败不会阻止其余项尝试保存，任务会列出失败原因。

关闭浏览器、更新／重新加载扩展、系统回收扩展进程都会中断处理。重新启动后，处理中任务标记为“已中断”，需要手动重试；尚未开始的任务继续排队。重试重新执行处理，但跳过已保存输出的再次下载，不支持从编码中途恢复。

任务快照、生成文件和诊断保存在本机 IndexedDB。当前不自动清理；不需要时请移除任务以释放空间。移除不会删除下载目录中的文件，也不会删除来源记录。尚未手动保存的 Android 输出会随任务一起移除。

## 实现与边界

提交时固定推文、媒体顺序、语言、主题、模板和处理限制，先写入数据库，再返回入队确认。内容脚本只提交请求，不拥有处理 Worker；后台使用持久后台页串行执行任务。修改后续设置不会改变已排队的快照，但动态处理开始时仍会检查实验性开关是否开启。

FFmpeg 仅在动态任务执行时加载，结束或取消后释放 Worker。持久后台页不等于浏览器退出后仍可运行，也不能防止 Android 系统回收进程。手机后台行为与手动保存仍需实机验证。

输出文件在交给浏览器前先存入任务数据库，保存失败仍可从任务页获取已生成文件。磁盘空间不足等数据库错误会明确报错，不返回入队成功。编码诊断按任务保留；一个任务包含多次动态编码时，当前保留最后一次报告。

## 人工回归

1. 桌面提交较长视频画框，确认入队后关闭原标签页，从扩展弹窗进入任务页，确认处理继续且文件自动保存。
2. 连续从不同推文提交原文件、图片画框和拼图，确认顺序处理，文件内容和命名仍对应各自推文。
3. 取消等待中／处理中任务，然后重试；检查没有重复保存已成功输出，其他任务继续执行。
4. 处理中重新加载扩展，确认该任务显示已中断，手动重试能完成。
5. Android 提交后保留任务页、关闭原推文，完成后手动保存；检查文件能正常打开。
