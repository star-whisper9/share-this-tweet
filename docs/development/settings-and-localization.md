# 设置与本地化

设置、模板和语言会同时影响面板、后台任务与生成文件。修改时需要处理当前界面、已经保存的旧数据，以及任务快照，不能只更新设置页上的一个控件。

## 设置的读取与保存

`shared/settings.ts` 定义 `ExtensionSettings`、`DEFAULT_SETTINGS` 和加载／保存入口。持久键分为：

| 键                          | 内容                                     | 保存时机           |
| --------------------------- | ---------------------------------------- | ------------------ |
| `share-this-tweet.settings` | 模板、画框位置、拼接样式、实验开关及限制 | 点击保存偏好       |
| `share-this-tweet.language` | `auto`、`zh-CN` 或 `en`                  | 切换语言后立即保存 |

语言独立保存，防止设置页较旧的模板草稿覆盖用户刚在弹窗选择的语言。`loadSettings` 还用语言修订号避免较慢的读取把界面切回旧语言；监听跨页面更新由 `watchLanguage` 完成，返回值用于注销监听。

`normalizeSettings` 负责兼容缺省数据。不同字段有自己的兼容规则，新增字段时需要明确缺省值、旧数据迁移和非法值的处理，不能把所有读取失败都转换成默认设置再写回。

设置页在成功加载后才允许编辑和保存。读取失败会保留错误状态并提供重试，不应让页面里的示例或初始默认值覆盖用户的历史设置。

### 增加一个偏好

通常需要检查以下位置：

1. 在 `shared/settings.ts` 中增加类型、默认值和归一化规则；若涉及实验限制，同步对应限制模块。
2. 在 `options/options.ts` 或 `options/experiments.ts` 中接入读取、写入、草稿比较、校验和恢复默认；控件定义位于 `options.html`。
3. 为控件及其错误添加中英文词条，确认语言切换后动态控件也会更新。
4. 如果影响导出，更新 `ExportJobRequest` 的运行时校验，并确认渲染读取的是提交时快照还是必须在执行时复核的当前开关。
5. 通过公开加载／保存和导出接口验证默认、旧数据、自定义值及失败路径。

模板、画框和拼接偏好在任务提交时固定，之后修改不会重写旧任务。实验开关在动态处理开始时还会复核；这与限制数值使用快照是两种不同的行为。

## 模板引擎与变量注册

| 文件                        | 职责                                 |
| --------------------------- | ------------------------------------ |
| `core/template.ts`          | 解析、变量范围校验和展开             |
| `core/template-fields.ts`   | 字段读取、日期格式和各编辑器可用变量 |
| `core/filename.ts`          | 文件名模板、字符清理与输出后缀       |
| `core/frame.ts`             | 画框模板与头像标记渲染               |
| `core/text-export.ts`       | 默认复制模板、投票和引用的组合       |
| `options/template-guide.ts` | 变量搜索、快捷插入和场景预览         |

模板只支持受限语法，不执行 JavaScript：

```text
{author.handle}
{author.name|未知作者}
{tweet.publishedAt:YYYY-MM-DD}
{?translation.text}{translation.text}{/translation.text}
```

缺失字段展开为空，可设置默认值；可选区块按字段是否有值决定显示，`0` 和 `false` 仍有值。区块不支持嵌套，默认值中的 `|` 和字面花括号不能转义。日期统一使用 UTC，支持格式由 `DATE_FORMATS` 定义。

### 变量范围由同一注册表决定

`fieldsForScope` 根据 `TemplateScope` 返回变量列表，编辑器和渲染器共同使用。画框与文件名只允许来源相关字段；复制模板支持正文、译文、投票、作者和引用信息，不提供媒体上下文变量及输出扩展名。

新增变量时先在字段注册表定义读取规则、类型说明、示例和日期／媒体标记，再确认各 scope 是否允许。若属于画框或文件名的来源字段，需要显式加入允许范围；不要仅在编辑器中增加一个快捷按钮。

帧中的 `author.avatar` 会渲染为头像标记，普通文本中的同名字段不是图像。保存引用媒体时，命名与画框使用该媒体所属推文的上下文，不能继续套用主推文作者。

### 保留自定义模板与兼容行为

默认复制模板有语言版本及旧版本识别。切换语言可以替换已识别的内置默认模板，但不能改写用户自定义的字符串。新增预设或调整默认值时，不应批量覆盖已经保存的自定义画框和命名模板。

未知变量、禁用变量、无效日期格式或不匹配区块会报错。旧模板应保留原文并提示修正，不能静默删掉字段使导出看起来成功。

复制模板未显式写引用变量或区块时，`buildTweetText` 自动追加一层引用；写入后由模板控制。投票也有对应的组合规则。修改默认模板时既要验证常规结果，也要验证没有译文、投票结果不可见和引用不可用的情况。

## 语言与词典

`shared/i18n.ts` 提供 `t`、`resolveLocale`、`getLocale`、`setLocale` 和 `localizeDocument`。词典按功能放在 `shared/locales` 中，包括 common、content、core、options、jobs、experimental 和 video。

简体中文词典定义 `MessageKey`，英文通过 `Record<MessageKey, string>` 覆盖相同的键。键采用稳定的语义名称，不使用整句中文作为标识。当前自动语言选择将中文浏览器语言映射到 `zh-CN`，其他语言映射到 `en`。

动态参数通过 `t` 一次插入：

```ts
const message = t('content.itemFailure', { index, error }, locale);
```

词条里使用 `{index}`、`{error}`。插值不会重新解析参数中的花括号，用户输入不能再次变成翻译占位符。需要字面花括号时，词条用以下写法：

```text
{{ 和 }}
```

这里是界面词典的转义规则，与上方用户模板的语法不同。缺少词条或参数时会抛错，不应该捕获后返回空文字。

### 静态节点与动态界面

HTML 中用 `data-i18n` 标记纯文本节点，属性分别使用 `data-i18n-placeholder`、`data-i18n-title` 和 `data-i18n-aria-label`。`localizeDocument` 会更新标记节点和语言属性。

不要把包含图标、按钮等子节点的父元素标为纯文本翻译，否则 `textContent` 更新会移除子节点。不要用 `innerHTML` 插入翻译，也不要扫描并替换推文正文或模板输入。

动态生成的控件与状态需要在语言变化时重新渲染，页面销毁时注销监听。任务开始时固定 `locale`，传递到后台和 Worker；异步任务的报错与输出文字不能依赖进程里随时可能变化的全局语言。

## 新增语言

1. 在各词典模块增加完整语言表，在 `i18n.ts` 注册 locale、catalog 和浏览器语言映射。
2. 在设置页、弹窗及对应类型与校验中加入语言选项，用该语言的原生名称显示。
3. 增加 `src/_locales/<浏览器语言代码>/messages.json`，供 Firefox 扩展管理器读取名称与描述。管理器语言跟随浏览器，与扩展内偏好分开。
4. 增加内置复制模板的语言版本，保留旧默认模板识别，不修改自定义模板。
5. 更新依赖 locale 的消息校验，尤其是导出任务与视频 Worker 中的允许值，并覆盖新语言的占位参数一致性。

界面文案可翻译，推文原文、作者、URL、文件内容、协议字段和模板变量名称不能作为界面文案改写。生成图片中需要翻译的标签使用任务携带的语言。

## 验证改动

相关测试包括 `settings`、`i18n`、`template`、`template-metadata`、`text-export` 和 `options-preview`，位于 `tests/<名称>.test.ts`。当前检查包含词条覆盖和中英文占位参数一致性；新增语言时需相应扩展。

模板测试可以通过 `renderTemplate` 等公开接口验证确定的输出数据；语言和控件测试使用状态、键覆盖及参数契约，不把整段产品文案当作稳定断言。

人工回归时，打开弹窗、设置页、任务页和推文面板再切换语言，确认状态同步；保留一份未保存的模板草稿，检查语言切换与偏好保存互不覆盖。还需检查长文案、窄屏、键盘操作，以及导出图片中的语言和日期布局。
