# Share This Tweet

面向 Firefox Android 的 X 分享增强扩展，当前处于 v0 开发阶段。

## 需求

- 仅在 X 推文详情页提供扩展操作入口。
- 保存图片原图，并通过可配置文件名模板附带推文元信息。
- 保存普通视频和 X GIF 对应的 MP4 视频。
- 复制包含正文、原推 URL 和 Tweet ID 的文本推文。
- 生成固定在图片底部、支持单栏/双栏布局的来源画框 PNG。
- 提供可读性良好的亮色和暗色扩展 UI。
