# Share This Tweet

面向 Firefox 的 X 推文分享增强扩展，当前 `v0.1.0` 功能实现已完成。

## 当前状态

- 仅在 X 推文详情页提供扩展操作入口。
- 支持照片原图、普通视频和 GIF 对应的 MP4 保存。
- 支持文件名模板和 Tweet 元信息。
- 支持复制包含正文、作者、原文链接和 Tweet ID 的文本推文。
- 支持照片底部单栏/双栏来源画框 PNG。
- 设置页支持文件名、画框和复制文本模板的保存、校验与预览。
- UI 支持亮色和暗色模式。
- macOS Firefox 已完成主要功能验证；Android 后续测试发现的问题将作为 `v0.1.1` 修复。

项目使用 TypeScript、npm 和 Vitest，许可证为 GPL v3。

## Roadmap

- `v0.1.1`：根据 Firefox Android 实机测试修复兼容性问题。
- 后续 `v0.x.0`：继续增强画框主题、媒体批量操作和更多推文导出能力。
